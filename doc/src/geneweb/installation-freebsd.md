# Installation sous FreeBSD

> Source : page [FreeBSD](https://geneweb.tuxfamily.org/wiki/FreeBSD) du wiki officiel.

Deux méthodes :

- **Installation manuelle** : suivre la procédure décrite pour [macOS](installation-mac.md), en remplaçant simplement `make` par `gmake`.
- **Via le gestionnaire de paquets** :
  ```bash
  pkg install geneweb
  ```
